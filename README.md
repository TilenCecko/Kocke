# 🎲 Kocke – Spletna igra s kockami

Preprosta spletna igra s kockami, izdelana v PHP, JavaScriptu, HTML in CSS. Igra omogoča igranje za več igralcev, nastavitev števila kock in krogov ter prikaz končnih rezultatov s podiumom in animacijami.

---

## 📌 Funkcionalnosti

* 👥 Podpora za 3 igralce
* 🎲 Izbira števila kock (1–3)
* 🔄 Izbira števila krogov
* 🏆 Samodejni izračun rezultatov
* 🥇 Podium zmagovalcev
* 🎆 Animacija ognjemeta ob koncu igre

---

## 🛠️ Tehnologije

Projekt uporablja:

* **PHP** – logika igre in delo s sejami
* **JavaScript** – animacije in interaktivnost
* **HTML5** – struktura strani
* **CSS3** – oblikovanje uporabniškega vmesnika

## 🎮 Kako igra deluje

1. Vpišeš imena igralcev.
2. Izbereš število kock in krogov.
3. Začneš igro.
4. Vsak igralec meče kocke.
5. Na koncu se izračunajo točke.
6. Prikaže se podium zmagovalcev.
